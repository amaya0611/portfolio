## Deploy to GitHub Pages
1. Create a repository and upload all files, keeping the folder structure.
2. Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
3. Your URL appears in the Pages settings after a minute or two.

## Before publishing
- Test the filters, the mobile menu, and the résumé download on the live URL.
- Your résumé PDF contains your phone number; replace it with a version without one if you prefer.
